## 3. 阶段三 · P0 精读（核心工作量）

### 3.1 读哪 8 篇、按什么顺序

| 序 | 论文 | 会议 | 代码 | 读它是为了拿到 |
| :-: | :-- | :-: | :-- | :-- |
| ① | FISHing（合成对比学习 · 遗传畸变） | MICCAI 2024 | [SimonBon/FISHing](https://github.com/SimonBon/FISHing) | 小样本 + 罕见类别时怎么"造"不确定性监督 |
| ② | PULPo（概率拉普拉斯金字塔配准） | MICCAI 2024 | [leonardsiegert/PULPo](https://github.com/leonardsiegert/PULPo) | 唯一覆盖"配准"的概率 UQ，不确定性驱动训练的写法 |
| ③ | 乳腺超声分割（MC Dropout × 集成） | MICCAI 2025 | [caladan-mama-mia](https://github.com/toufiqmusah/caladan-mama-mia) | 两种基线组合的工程模板 + 边界校准 |
| ④ | MedSymmFlow（对称流匹配） | MICCAI 2025 | [caetas/MedSymmFlow](https://github.com/caetas/MedSymmFlow) | 生成式路线怎么和判别校准对齐 |
| ⑤ | LLM 增强保形预测 | NeurIPS 2024 | [conformal-safety](https://github.com/jjcherian/conformal-safety) | 保形预测搬到语言模型的理论与实现 |
| ⑥ | CalibPrompt（校准感知提示） | BMVC 2025 | [CalibPrompt](https://github.com/iabh1shekbasu/CalibPrompt) | 不重训底座、只调提示层做校准 |
| ⑦ | MLLM 少样本校准偏差 | MICCAI 2025 | [fairness-mllm](https://github.com/xingbpshen/medical-calibration-fairness-mllm) | 子群校准偏差怎么被 few-shot 示例放大 |
| ⑧ | 医学 VLM 推理忠实性（TAIX-VQA） | ML4H 2025 | [cot-eval](https://github.com/jomoll/cot-eval) | 8 类扰动下的评测协议，可直接改成校准实验 |

> 顺序逻辑：先影像（分割/配准/生成）→ 再语言与多模态。前 4 篇共用"医学图像 + 公开数据"的工程习惯，后 4 篇共用"预训练模型 + 评测协议"的思路，成组读省力。

### 3.2 每篇的固定五步（做完才算读完）

| 步 | 动作 | 判据 |
| :-: | :-- | :-- |
| 1 环境 | clone → 建独立 env → 跑 `demo` 或加载作者权重 | 有一条能跑通的命令写进笔记 |
| 2 数据 | 查 license、样本量、**患者级**划分（不是图像级） | 能说出"训练/测试是否同患者" |
| 3 复现 | 只复现 1 个你关心的数字（AUROC / ECE / 覆盖率） | 与论文差 ≤2 个点，或能解释差距 |
| 4 拆方法 | 把 loss 与推理路径压成 3 行伪代码 | 不看论文能默写出来 |
| 5 记边界 | 写"什么条件下会失效 + 能不能迁到我的场景" | 至少 2 条失效条件 |

### 3.3 每篇统一记录模板（复制到笔记）

```text
【论文】名称 / venue / 代码链接
【任务】分割·分类·配准·生成·QA；模态；数据集与规模
【要解决什么】一句话（不是"提升性能"，是"哪种不确定性没被建模"）
【方法】输入→特征→不确定性从哪来→怎么训练→推理几次前向
【关键数字】主表 2 个数 + 消融里最能说明问题的那 1 个
【成本】训练 GPU 时 / 推理单例耗时 / 显存
【失效条件】① ②（越具体越好）
【可迁移点】能挂到我哪个模型、需要改哪一层
【一句话评价】值不值得复现第二遍
```

## 8. 验收标准（Definition of Done）

1. **可追溯**：每条结论都能点到"某篇论文的某张表"或"某行代码"，不出现"研究表明"这种空话。
2. **可复现**：8 篇 P0 至少 5 篇跑出过真实数字，命令写进笔记。
3. **可核查**：实验室每个团队 ≥2 条可点开的证据链接。
4. **可用**：数据集表里每个数据集都有 license 与划分方式，能直接决定"能不能用"。
5. **可重建**：clone 仓库后 `python scripts/build_index.py` 与 `python scripts/draw_landscape.py` 两条命令能重生成索引和图。
6. **可讲**：三块内容能在 10 分钟内讲完，且每块有一张图。

## 9. 四个必避的坑

| 坑 | 表现 | 规避 |
| :-- | :-- | :-- |
| 可交换性被悄悄破坏 | 多中心数据按图像随机划分，CP 覆盖率虚高 | 划分前先按中心/患者分组 |
| 数据集泄漏污染 UQ 评估 | BUSI 同患者图像跨 train/test | 用患者级 split，报告里写清 |
| ECE 分箱数改变结论 | 15 bin 说校准好，50 bin 说很差 | 固定 bin 数并同时报 Brier |
| 把第三方框架当官方代码 | ultralytics / MONAI 链接被当成作者实现 | 只认作者仓库；框架链接标"依赖" |
