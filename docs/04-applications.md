## 2. 三个高价值场景的深入分析

### 2.1 分割：从"像素方差"到"体积保证"

```text
像素级 softmax 方差   →  没有真值可对（标注者本身有分歧）
      ↓ 升级
不确定性图 + 挑错排序  →  SegWithU：校准图管概率、排序图管"哪里最可能错"（AURC）
      ↓ 再升级
保形体积保证         →  ConVolt / 形态学预测集：控制"预测集的体积/连通性"
      ↓ 终局
多评分者体积协议     →  CURVAS：用 4–10 位医生的分歧体积当校准真值
```

**可直接迁移的实验设计**：在 LIDC-IDRI（4 位放射科医生各自勾画）上，检验"ECE 下降是否等于模型学到了标注歧义"——2026 年几乎空白。

### 2.2 分类：长尾与多中心的"最差组"问题

- 平均 ECE 很低 ≠ 每个病种都校准好。CXR-LT 2026（MedIA）提供了多中心、长尾、零样本三重压力的官方基准。
- 保形预测的"边际 90% 覆盖"在尾部病种上可能远低于 90%——需要类条件/子群条件化（TACP、SGCP 思路），或 CalCErt 式逐 bin 认证。
- 模型选择的启示（FOCUS，NeurIPS 2026）：**域专用预训练 + 自监督的底座，校准显著优于通用底座，且标准再校准抹不平差距**——校准先于再校准，从选模型开始。

### 2.3 语言模型场景：校准与验证切开

- CARE（摘要）：在 LLM 外挂一层保形"安全层"，对生成内容做风险受控的后处理——**不动模型**，工程上最容易落地。
- C-MoA（2026）：明确论证"校准（概率对不对）≠ 验证（答案可否证伪）"，混合多智能体路由要做可证伪性感知。
- 医学 VQA（COLM 2026）：过自信与幻觉强相关；缓解要在生成端感知幻觉，而不是事后压概率。

## 3. 公开数据集地图（按能支撑的校准实验划分）

| 数据集 | 模态/任务 | 能支撑的校准实验 |
| :-- | :-- | :-- |
| **LIDC-IDRI** | CT 肺结节，4 医生独立勾画/评分 | ⭐ 标注分歧作为校准真值；aleatoric 校准 |
| **CURVAS (挑战赛数据)** | 多器官 CT，多评分者体积 | 多评分者体积校准协议 |
| **CXR-LT 2026** | 胸片，长尾+多中心+零样本 | 最差组/类尾覆盖、跨中心校准 |
| **ACDC / M&Ms** | 心脏 MRI（M&Ms 多中心多厂商） | 分割 UQ + 跨中心偏移 |
| **BraTS / BraTS-Mets** | 脑肿瘤 MRI | 3D 分割不确定性、AURC |
| **LiTS** | 腹部 CT 肝脏分割 | 3D 分割 UQ、推理成本对比 |
| **ISIC (2016–2024)** | 皮肤镜 | 长尾分类校准、增强影响 |
| **Camelyon16/17** | 病理淋巴结 | WSI 弱标注校准 |
| **DR 筛查集（EyePACS / APTOS）** | 眼底 | 选择性筛查、弃权策略 |
| **MIMIC-CXR + 报告** | 胸片+文本 | 报告置信、VQA |
| **VQA-RAD / SLAKE / TAIX-VQA** | 医学 VQA | 表述置信、幻觉评测 |
| **MIMIC-III/IV、eICU** | EHR | 跨队列风险校准、缺省模态 |
| **MedMNIST 家族** | 轻量多模态 | 快速原型与消融 |

> ⚠️ **数据集陷阱**（文献库中踩过的坑）：
> 1. **BUSI 乳腺超声**：多篇 UQ 论文把同一患者不同帧分进训练/测试集，患者级泄漏会让不确定性指标虚高——务必患者级划分。
> 2. **ECE 的 bin 设置**：15 bins 与 50 bins 可能给出相反结论，报告时给出多条 bin 曲线或用 SW-ECE。
> 3. **可交换性悄悄破坏**：时间序列、同一患者多次检查、多中心混合排序后随机切分——都会破坏保形预测的覆盖保证，需按结构分组切分。
> 4. **VLM 弱标签**：用 VLM 生成的"置信度"当真值会引入模型间相关偏差。

## 5. 评价指标速查

| 层面 | 指标 | 说明 |
| :-- | :-- | :-- |
| 概率校准 | ECE / ACE / NLL / Brier | 报告 bin 数；组内分别报 |
| 排序/挑错 | AUROC(错误检测)、AURC、E-AURC | 分割用体素级、分类用样本级 |
| 覆盖 | 覆盖率、预测集大小、区间宽度 | 保形方法必报**子群覆盖** |
| 决策 | 风险–覆盖曲线、AURC@α、弃权率 | 部署向场景 |
| 临床一致性 | 与标注者分歧的相关性（如 Joanis dice 熵） | 新兴指标，2026 加分项 |
