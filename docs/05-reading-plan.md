## 每周笔记模板

```markdown
# Week 0X · <论文简称>

## 1. 一句话总结
## 2. 方法拆解（输入→机制→输出，画一张图）
## 3. 实验设置（数据 / 对比方法 / 指标）
## 4. 方法边界（它自己承认的 + 我看出来的）
## 5. 复现记录（环境坑 / 随机种子 / 与论文数字的差距）
## 6. 对我们选题的接口（能借什么、避什么坑）
```

---

## 复现checklist（每篇 P0 都过一遍）

- [ ] 环境能跑通（记录 commit / 依赖版本）
- [ ] 至少一个数据集上对上论文主表数字（±5%）
- [ ] 画出它输出"不确定性"的位置（logits 前 / 后 / 特征层）
- [ ] 记录推理开销（单样本毫秒数、显存）
- [ ] 明确它**没**解决的问题（写进方法边界）

## 里程碑自检

- **第 4 周末**：能不看笔记说清"保形预测为什么在多中心数据上会失效"。
- **第 6 周末**：手上有 2 个跑通的代码库 + 1 个自己重实现的头。
- **第 8 周末**：proposal 能回答：①难点是什么 ②为什么现有方法不行 ③我的验证路径 ④数据在哪。
