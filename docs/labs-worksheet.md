## 三、四个公开来源，具体怎么查

### 1) DBLP —— 查"这个人到底发在哪"（最可靠，先做这个）

1. 打开 `dblp.org`，搜索框输入 `calibration medical` 或团队 PI 姓名拼音；
2. 点作者名进入作者页，右上角 `venue` 过滤：勾 **MICCAI / IPMI / TMI / Medical Image Analysis / NeurIPS / ICML / ICLR**；
3. 只保留 2023 年之后的条目，抄"标题 + venue + 年份 + doi 链接"。
   - 优点：不会被主页"精选论文"误导；缺点：中文期刊和 arXiv 不全。

### 2) Google Scholar —— 查"这个方向他是不是持续在做"

1. 进 PI 主页 → 点 `Cited by` 排序；
2. 搜索框内限定团队：`calibration "medical image"`，再用左侧 `Since 2023`；
3. **看连续性**：同一主题 ≥2 篇且年份分散（不是一篇孤文）才算"在做这个方向"。只看单篇高被引会误判。

### 3) GitHub 组织页 —— 查"有没有可复现代码"

1. 搜团队名 / 论文名；2. 看 `Last commit` 是否在 12 个月内；3. 看 README 有没有训练脚本与权重链接。
   - 只有 `requirements.txt` 和图片的仓库，标"未开源（仅占位）"。

### 4) OpenReview / 会议接收列表 —— 查"最新但还没正式发表的"

1. `openreview.net` 搜 `conformal medical`，看 NeurIPS/ICLR 的接收状态（Accept 才引用）；
2. MICCAI 官网的 accepted papers 列表按机构名 `Ctrl+F` 搜（如 `Tsinghua`、`CUHK`）。
   - 这一步能抓到 2026 年还没进 DBLP 的工作，但**必须区分 oral/poster/workshop**。

> 检索式直接复制：
> - `"conformal prediction" medical imaging`
> - `calibration "medical image segmentation" uncertainty`
> - `"uncertainty quantification" MICCAI 2026 Tsinghua`
> - `site:github.com conformal medical segmentation`

## 四、判断标准：三条硬门槛（防"蹭方向"）

一篇论文 / 一个团队要进表，**三条全过**：

1. **主题对**：标题或摘要出现 calibration / uncertainty / conformal / risk control 之一，而不是只在 related work 里提一句；
2. **动的是方法**：改损失、改训练、改推理、改评测协议；纯"拿现成模型做临床验证"不算（那是应用，另设一列）；
3. **能落地**：有代码，或至少给了可复现的评测协议与数据划分。两条都没有 → 标"待确认"，不进结论段。

若只满足 1、不满足 2 → 记到"应用侧"而不是"方法侧"；这类工作适合写在"国内应用现状"，不要写成"方法团队"。

## 五、每队 20 分钟的标准动作（SOP）

| 分钟 | 动作 | 产出 |
| :-: | :-- | :-- |
| 0–3 | DBLP 搜 PI 姓名，勾 venue 过滤，截 2023 后条目 | 候选论文 5–10 条 |
| 3–8 | 从中挑 3 篇标题带 calibration/uncertainty/conformal 的 | 代表作 3 篇 |
| 8–12 | 逐篇看摘要：是改方法还是纯应用？ | 过三条硬门槛的留下 |
| 12–16 | 搜 GitHub 仓库名；看 last commit 与 README | 开源字段 |
| 16–20 | 填 CSV 一行 + 写一句"为什么是对标/可合作" | 1 行完成 |

**只做 3 队也能交差**：优先 清华 TSAIL、上海 AI Lab（OpenMEDLab）、港中文 —— 这三家与"条件覆盖 / 基础模型校准 / 可信分割"最直接，讲汇报时够用；其余标"后续补充"。

## 六、证据分级与写法规范

| 等级 | 依据 | 允许的表述 |
| :--: | :-- | :-- |
| A | 论文原文（DOI/arXiv 可打开） | "该团队在 MICCAI 2025 提出 X，将覆盖率提升到 Y" |
| B | 机构主页 / 官方实验室页面 | "团队主页列出的方向包括 X" |
| C | 新闻报道 / 二手转述 | 只能写"据报道"，**不进结论** |

**句式模板**（直接抄）：

> `机构 · 团队（PI）`｜方向：`条件覆盖 / 证据学习`｜代表作：`标题（Venue 年份）`｜开源：`github.com/xxx`｜活跃度：`2026 年 MICCAI 2 篇`｜定位：`可对标——同样做子群覆盖，但未涉及多评分者真值`

## 七、四个常见错误（都是我被问过的）

| 错误 | 后果 | 改法 |
| :-- | :-- | :-- |
| 用"主要从事/致力于"描述 | 无信息量，一问就露 | 换成一篇文章 + 一句结论 |
| 把综述当代表作 | 说明不了方法能力 | 综述单列"综述"标签，不算代表作 |
| 把合作论文算成本组 | 作者单位对不上 | 看第一作者/通讯作者单位 |
| 只查中文报道 | 时间滞后 1–2 年 | 以 DBLP + MICCAI 接收列表为准 |
