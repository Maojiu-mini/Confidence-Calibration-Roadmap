# 🧍 一个人怎么做：单人执行路线（21 天）

> 前提：只有你一个人，每天能拿出 **2 小时**，周末各 **4 小时**。
> 原则：**砍范围，不砍深度**。8 篇 P0 → 3 篇；12 个场景 → 3 个；8 个国内团队 → 3 个。宁可 3 条能点开，不要 20 条靠印象。

---

## 先看这张取舍表（这一步最重要）

| 原计划 | 单人版 | 为什么 |
| :-- | :-- | :-- |
| P0 精读 8 篇 | **3 篇**（⑤ LLM 保形 · ③ 超声分割 · ② PULPo） | 8 篇按五步法约 80 小时，一个人做不完；3 篇足够撑起"方法对比 + 复现能力" |
| 实验室 8 个机构 | **3 个**（清华 TSAIL · 上海 AI Lab · 港中文） | 这 3 家与你的选题最直接，讲汇报够用 |
| 12 个医疗场景 | **3 个**（LIDC-IDRI · CURVAS · CXR-LT） | 场景表已有初版，补 license 只补你要用的 |
| 写一篇综述 | **不写** | 综述是三个人的活；你写 3000 字方法梳理即可 |
| 全部 68 篇都读 | **12 篇**（P0 3 + P1 5 + P2 4） | 其余靠 `papers.csv` 字段支撑，用时再查 |

**一句话**：你的目标不是"覆盖全部"，而是"每条结论都有出处，且能亲手跑出一个数字"。

## 第 1 步 · 今晚 2 小时：把方法对比"讲一遍给自己听"

1. 打开 `docs/01-methods.md`，只看 13 族速览表和六维矩阵（20 分钟）；
2. 关掉文档，**手写**一张纸：13 族各一句话 + 哪三族适合"不能重训"的场景（30 分钟）；
3. 对照原文补漏，把写错的地方记在纸上（20 分钟）；
4. 打开 `data/papers.csv`，随便抽 5 篇，试着说出它属于哪族、为什么（30 分钟）。

- 产出：一张手写 A4（拍照存 `notes/` 也行）。
- 判据：能不看文档说出"MC Dropout 为什么不适合 3D 分割""保形预测什么时候会失效"。
- **为什么先做这个**：方法对比是你汇报时唯一不会被追问倒的部分；先把它变成"你自己的话"，后面读论文才有坐标系。

## 第 2 步 · 第 1 周：复现第一篇（⑤ LLM 保形，NeurIPS 2024）

选它的理由：代码最完整、CPU 能跑、不依赖医院数据。

| 天 | 动作 | 时长 |
| :-- | :-- | :-- |
| D1 | clone 仓库、建 env、读 README 的 quickstart | 1.5h |
| D2 | 按 quickstart 跑一个最小示例（哪怕只是打分 + 构造预测集） | 2h |
| D3 | 换一个自己的小数据（20 条医学 QA 手写即可），跑出覆盖率 | 2h |
| D4 | 记录：实际覆盖率 vs 名义 90%，差多少、为什么 | 1.5h |
| D5 | 按 9 字段模板写第一份笔记 `notes/p0-05-llm-conformal.md` | 1.5h |

- 判据：**有一个自己跑出来的覆盖率数字**（不是抄论文的）。
- 跑不通怎么办：只读 `conformal-safety` 里构造 prediction set 的那 30 行，手写复现一遍逻辑，笔记里写"未能跑通，卡在 X"，也算完成——**诚实记录卡点本身就是能力**。

## 第 5 步 · 第 3 周前半：3 个数据集、1 个场景判定

**只查你会用的三个数据集**（各 15 分钟）：

| 数据集 | 查什么 | 记在哪 |
| :-- | :-- | :-- |
| LIDC-IDRI | 4 位医生标注的结节评分在哪一列、怎么聚合 | `04-applications.md` 表 |
| CURVAS | 多评分者体积数据的获取门槛、是否要注册 | 同上 |
| CXR-LT 2026 | 长尾类别清单、子组标签是否公开 | 同上 |

**只做一个场景判定**（2 小时）：LIDC + CURVAS 的"标注分歧作为校准真值"——

- 数据够不够（样本量、评分者数）；
- 基线是谁（温度缩放 / 标签平滑 / 深度集成）；
- 指标怎么定（ECE vs 分歧拟合度，用一条曲线）；
- 风险写两条（评分者间一致性低怎么办、样本少怎么统计）。

产出：`notes/scenario-lidc.md` 一页。

## 一个人最容易死在哪（提前避开）

| 死法 | 症状 | 解药 |
| :-- | :-- | :-- |
| 环境地狱 | 花三天装依赖，一篇没读 | 用 Colab / Docker；装不上就只读代码 |
| 追 SOTA | 想让复现数字超过论文 | 只求"差 ≤2 点或能解释"，允许更差 |
| 范围膨胀 | 想同时读 8 篇、查 8 队 | 守住 3/3/3；想加先删一个 |
| 不做笔记 | 一周后全忘 | 每天最后 30 分钟强制写 |
| 只读不跑 | 汇报时被问"你跑过吗" | 每月至少 1 个自己跑出的数字 |
